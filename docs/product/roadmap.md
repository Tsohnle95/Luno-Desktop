# Product Roadmap

This file contains proposals only. Implemented behavior belongs in source,
tests, and the architecture documents.

## Deferred

- Android persistent playback history
- Android volume control
- Android drag-to-reorder playlists
- Android download-all for playlist detail
- Desktop controller decomposition

## Open Decisions

- Whether Android should add broader MediaStore scanning alongside SAF import
- Whether Android dependency injection should move beyond manual wiring
- Whether desktop and Android need additional transfer providers
