# Reviewed Desktop Release Inputs

This directory is supplied by the release owner and is intentionally not
generated by the build. Before a release, add executable macOS universal or
architecture-matched files at `release-input/bin/ffmpeg`,
`release-input/bin/ffprobe`, and `release-input/bin/yt-dlp`.

The files must match the pinned versions and architecture claims in
`release/desktop-binaries.json`. Replace every manifest placeholder with a
reviewed SHA-256, and attach the exact upstream license notices and build
configuration to the release review. Do not download binaries in the build or
commit credentials, signing certificates, DMGs, or these executable inputs.

Provision with:

```sh
LUNO_BINARY_SOURCE_DIR=release-input/bin ./scripts/provision-desktop-binaries.sh
```

The provisioning script fails closed when an input, reviewed checksum, or
checksum match is missing.
